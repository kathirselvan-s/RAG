# TechNova Product Catalog

## NovaRAG Platform
NovaRAG is an enterprise-grade Retrieval-Augmented Generation system that allows companies to build private chatbots over their internal documents, PDFs, emails, and databases.

Key Features:
- Supports 20+ file formats
- Hybrid search (vector + keyword)
- Multi-modal support (text + images)
- On-premise and cloud deployment
- Role-based access control
- Automatic document ingestion and versioning

Pricing: Starts at $999/month for 50 users.

## VisionAI
Real-time defect detection system using computer vision for manufacturing lines.
Accuracy: 99.2% on industrial datasets.
Supported industries: Automotive, Electronics, Pharma.

## AutoML Suite
No-code platform that lets business users train ML models by simply uploading CSV files and selecting target columns.
Supported algorithms: XGBoost, LightGBM, Neural Networks, Random Forest.
